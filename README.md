# .github

Account-wide GitHub defaults for [@ohneben](https://github.com/ohneben).

Files here apply to every repository on the account that does not ship its own
copy — see [default community health files](https://docs.github.com/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

| File | Effect |
|---|---|
| [`.github/FUNDING.yml`](./.github/FUNDING.yml) | Default sponsor button (Buy Me a Coffee) on all repositories |

> Note: the sponsor button only renders on a repository once **Settings → General →
> Features → Sponsorships** is enabled for that repository.
